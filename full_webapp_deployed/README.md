# Badminton Analytics 🏸
This application performs 3D trajectory reconstruction and shot classification for badminton rallies.

## Features
- **Court Calibration:** Automatic court keypoint detection.
- **AI Tracking:** Shuttlecock and player pose estimation.
- **Physics Engine:** 3D trajectory optimization using drag and gravity models.
- **Shot Classification:** 5D Fusion (2D + 3D) for stroke identification.
